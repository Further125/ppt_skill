## [1.0.0] - 2026-07-03

### 新增
- JSON 驱动的 PPT 生成流水线
- 20+ 种幻灯片布局，包括封面、图表、表格、时间轴、团队、流程、树状图、词云等
- 约束布局系统，支持二分查找字号和 attach-chain 定位
- 声明式布局 Schema，支持百分比坐标
- 意图路由，根据内容自动推断布局
- 主题引擎，内置多种配色方案
- 富文本支持（按 run 设置粗体、颜色、字号）
- 自由形状，支持遮罩、裁剪和层级控制
- 原生图表（柱状图、折线图、条形图、饼图、环形图、面积图、雷达图、气泡图、散点图、组合图）
- 高级图表（瀑布图、漏斗图、甘特图）和词云
- 导出工具：PDF、长图、HTML 演示文稿
- QA 检查工具，检测溢出和空幻灯片
- 快照工具，截取页面或区域
- 模板分析和 Schema 自动生成
