## [1.0.0] - 2026-07-03

### Added
- JSON-driven PowerPoint generation pipeline
- 20+ slide layouts including cover, chart, table, timeline, team, process, tree, wordcloud
- Constraint layout system with binary-search font sizing and attach-chain positioning
- Declarative layout schemas with percentage coordinates
- Intent router for automatic layout inference
- Theme engine with built-in color palettes
- Rich text support (bold, color, size per run)
- Free-form shapes with masks, crops, and z-order control
- Native charts (column, line, bar, pie, doughnut, area, radar, bubble, scatter, combo)
- Advanced charts (waterfall, funnel, gantt) and wordcloud
- Export tools: PDF, long image, HTML slideshow
- QA check tool for overflow and empty slides
- Snapshot tool for page/region capture
- Template analyzer and schema auto-generation
